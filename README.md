# 大聯盟盲標對決：獨立網站版

這個資料夾就是整個網站。遊戲有兩個版本：

- `index.html`：**多人版**。單人對戰、同一台輪流玩、線上對戰都有，放上 Netlify 用。
- `大聯盟盲標對決單機.html`：**單機版**。只有單人對戰和同一台輪流玩，不需要網路連線設定，不用架網站，直接雙擊就能在瀏覽器裡玩。
- `firebase-config.js`：多人版線上對戰用的 Firebase 設定
- `firestore.rules`：資料庫的安全規則，要貼到 Firebase
- `source/`：產生上面兩個網頁的原始檔和抓數據的程式，說明在 `source/README.md`。要改遊戲請改這裡，不要直接改 `index.html`。
- `epl/`：**英超版**（Blind Auction FC，只有英文）。`epl/index.html` 直接雙擊就能玩，原始檔和說明在 `epl/source/`。整個資料夾放上 Netlify 後，網址加上 `/epl/` 就是英超版。

另外，旁邊的 `mlb-auction-單機版` 資料夾裡只有一個 `index.html`，內容和單機版一樣，是給 Netlify 當第二個網站用的。它由 `source/build.py` 自動產生，不在這個 GitHub 專案裡。

不設定 Firebase 也能玩「同一台輪流玩」。要和朋友各用自己的裝置連線，才需要做下面的第一部分。

開賽時可以選聯盟（美國職棒大聯盟或中華職棒）、賽制（單場、三戰兩勝、七戰四勝），以及名額（先發 3～6、中繼 2～8、終結者 1～3、板凳打者 0～3；七戰四勝至少 4 位先發）。線上對戰由房主在房間裡選。

球員總評是用同類球員（打者、先發、中繼＋終結者）裡的排名換算的。任何守位的打者都可以放 DH。

打者分成主守位和副守位：上季在主守位以外的某個守位出賽滿 30 場（MLB），或守滿 150 局（中職，大約 17 場完整比賽），那裡就是他的副守位。選秀時他可以填副守位的名額。排在副守位時，守備值用他在那個位置的真實數據（MLB 是 Baseball Savant 分守位的守備跑分，中職是野球革命分守位的 UZR，捕手兩邊都用框界跑分）。場數少的會往平均值拉回，抓不到數據時才退回「守得好的打 7 折、牽涉捕手算 -2」。排到沒守過的位置，守備會差很多。守位資料要先執行 `python3 source/fetch_positions.py 2026` 才會有。

比賽前可以排打序（點兩個棒次就能互換）、換先發；投手有體力條，連續出賽會更容易失分；比賽中的關鍵時刻會問你要不要換投或換代打（也可以勾「自動調度」交給系統）。在手機或平板上「同一台輪流玩」時，選秀畫面會改成左右兩邊各有自己的名單和競標區。三戰兩勝和七戰四勝會顯示系列賽累計的打擊率、OPS、防禦率，系列賽結束時選出系列賽 MVP。

線上對戰有時間限制：賽前調整陣容 3 分鐘，時間到自動確認；比賽中的換投、代打 1 分鐘，時間到由系統自動決定。

右上角的按鈕可以切換中文／English，選擇會記在這台裝置上。線上對戰時，兩個人可以各用不同語言。

## 第一部分：設定 Firebase（線上對戰用，約 10 分鐘）

1. 到 https://console.firebase.google.com 用 Google 帳號登入，按「新增專案」。名稱隨意，例如 `mlb-auction`。Google Analytics 可以關掉。
2. **開啟匿名登入**：左側選單「建構 → Authentication」→「開始使用」→「登入方式」分頁 →「匿名」→ 啟用 → 儲存。
   玩家不用註冊，打開網頁就會自動拿到一個匿名身分，用來記住誰是玩家 A、誰是玩家 B。
3. **建立資料庫**：左側「建構 → Firestore Database」→「建立資料庫」。
   - 地區選 `asia-east1 (台灣)`，建立後就不能改。
   - 模式選「正式版模式」。
4. **貼上安全規則**：在 Firestore 頁面上方點「規則」分頁，把 `firestore.rules` 的內容整段貼上，取代原本的內容，按「發布」。
5. **取得網頁設定**：左上角齒輪 →「專案設定」→「一般」分頁往下捲到「你的應用程式」→ 點網頁圖示 `</>` → 取個暱稱 → 註冊應用程式（不用勾 Firebase Hosting）。
   畫面會出現一段 `const firebaseConfig = { apiKey: ..., ... }`。
6. 用文字編輯器打開 `firebase-config.js`，把那六個值填進對應的引號裡，存檔。
   這段設定是公開的識別碼，不是密碼，放在網站上沒關係，資料的保護靠第 4 步的規則。

### 房間自動刪除（3 天）

每個房間最後一次有動作的 3 天後就會過期：過期的房間沒辦法再加入，有人打開線上對戰頁面時，網站會順手把過期的房間刪掉。這部分已經內建，不用設定。

如果想讓 Firebase 自己準時刪除（就算沒人打開網站），可以另外開「存留時間（TTL）」政策：Firestore Database →「存留時間」→「建立政策」，集合群組填 `rooms`，時間戳記欄位填 `expireAt`，按建立。Google 通常會在過期後 24 小時內刪除。如果你的方案不能開這個功能，略過也沒關係，網站內建的清除一樣有效。

**更新提醒**：3 天自動刪除這一版的 `firestore.rules` 有改過。如果你的 Firebase 還是舊規則，請照第一部分第 4 步再貼一次並按「發布」，不然建立房間會被拒絕。

## 第二部分：把網站放上網路（免費，約 3 分鐘）

最簡單的是 Netlify Drop：

1. 到 https://app.netlify.com/drop ，註冊或登入。
2. 把整個 `mlb-auction-site` 資料夾拖進網頁中間的框框。
3. 幾秒後會拿到一個網址，例如 `https://xxxx.netlify.app`。可以在 Site settings 裡改成好記的名字。
4. **回到 Firebase 加入網域**：Authentication →「設定」分頁 →「已授權網域」→「新增網域」，填入你的 Netlify 網域（例如 `xxxx.netlify.app`，不要加 `https://`）。

之後要更新網站，在 Netlify 的 Deploys 頁面把新的資料夾再拖一次就好。

單機版網站也一樣：另外建一個 Netlify 網站，拖進去的是 `mlb-auction-單機版` 資料夾。單機版不用 Firebase，所以不用做第 4 步。

## 第三部分：更新 GitHub

這個資料夾已經是 Git 專案（`.gitignore` 會排除 `.DS_Store` 這類系統檔）。改完檔案後：

1. 在 `mlb-auction-site` 資料夾裡執行 `python3 source/build.py`，重新產生網頁。
2. 打開 GitHub Desktop，左下角寫一句說明，按「Commit to main」。
3. 按上方的「Push origin」。

## 怎麼和朋友玩

1. 打開網址，點「線上對戰」→「建立房間」，你會拿到一組 4 碼房號。
2. 把網址和房號傳給朋友。朋友打開後點「線上對戰」，輸入房號加入。
3. 第三個人用同一組房號加入的話，會變成觀戰，只能看不能操作。

## 常見問題

- **重新整理或斷線**：用同一個瀏覽器回到網頁，按「回到 XXXX」就會接著打。如果換了瀏覽器或手機，會被當成新的人，只能觀戰。
- **出現「Firebase 連線失敗」**：通常是匿名登入沒有啟用（第一部分第 2 步），或 `firebase-config.js` 的值貼錯。
- **出現「寫入被拒絕」**：確認第一部分第 4 步的規則有按「發布」。
- **費用**：Firebase 的免費方案每天有 2 萬次寫入，一場對戰大約用 150 次，自己和朋友玩不會超過。Netlify 免費方案也足夠。
- **網址是公開的**：知道網址的人都能打開網站，但沒有房號就進不了你們的房間。
