# NBA 盲標對決原始檔

網頁是 `nba/index.html`，由這裡的檔案產生。要改遊戲請改這裡，不要直接改 `nba/index.html`。中英文都有，可以單人對電腦、同一台輪流玩、線上對戰。線上對戰和棒球版共用同一個 Firebase 專案和同一套 `firestore.rules`，房間會記下 `cfg.game='nba'`，所以棒球版的房號在這裡會被擋下來，反之亦然（棒球版沒有 `cfg.game` 的房間一律當作棒球）。

- `template.html`：遊戲的程式和版面。以棒球版（`source/template.html`）為底：選秀、交易、線上房間、同步、決定時限都沿用；球員卡、陣容、比賽模擬、比賽畫面改寫成籃球。
- `pool.json`：球季數據，每位球員的整季累計數據，加上 USG%、BPM、OBPM、DBPM。
- `build.py`：把上面兩個合起來，產生 `nba/index.html`。
- `fetch_stats.py`：抓數據。先試 NBA.com；NBA.com 會擋雲端主機，所以通常會改用 Basketball Reference。

## 更新數據

GitHub Actions 的「Fetch NBA stats」流程會抓數據並存回分支。只要改到 `fetch_stats.py` 並推上去，它就會自動執行；合併到 `main` 之後，也可以在 Actions 分頁按「Run workflow」手動執行，季別填 `2026-27` 這種格式。在自己電腦上執行也可以：

    pip install nba_api pandas lxml
    python3 nba/source/fetch_stats.py 2025-26
    python3 nba/source/build.py

## 規則和模擬

- **陣容**：先發 2 名後衛、2 名前鋒、1 名中鋒，替補 0–3 人（開賽前設定，不限位置）。球員的位置以 Basketball Reference 登錄的主要位置為準：PG、SG 算後衛，SF、PF 算前鋒，C 算中鋒。
- **綜合評價**：每 36 分鐘的 Hollinger game score，依上場時間往同位置平均值拉回，再加上 BPM，然後在同位置裡排名，換算方式和棒球版用同一條曲線。
- **比賽**：一次模擬一個球權。由誰出手，看在場五人的使用率（出手、罰球、失誤）；結果依那位球員本季的兩分、三分、罰球命中率和失誤率，再用防守端在場五人的 DBPM、抄截、阻攻調整。沒進就比雙方在場球員的進攻籃板和防守籃板，決定誰搶到。
- **體力**：在場上每分鐘掉 1.55%，坐板凳每分鐘回 2%，節間回 4%，中場回 12%。體力越低，命中率越低、失誤越多。前兩場上場越久，下一場開賽時體力越低。
- **節間調度**：第 2、3、4 節和延長賽開始前，兩隊可以同時換人和改戰術。決定的存法是 `dec[game]["節次:隊伍"]`，所以兩隊不用互相等。線上每次決定限時 1 分鐘，時間到就採用建議。
- **戰術**：平衡、主攻內線（少投三分、內線命中率和罰球較多）、狂投三分、加強防守（對手命中率和失誤變差，但自己比較累）、快攻跑轟（球權變多、上籃比較好進，但失誤多、比較累）。
- **校準**：讓真實 29 支球隊各自上場時間最多的 8 人互打，每隊每場平均約 114 分（實際約 115），主場勝率約 57%。
