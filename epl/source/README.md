# 英超版原始檔（Blind Auction FC）

英超版只有英文介面，玩法有單人對電腦和同一台輪流玩，沒有線上對戰。網頁是 `epl/index.html`，由這裡的檔案產生。要改遊戲請改 `template.html`，不要直接改 `epl/index.html`。

- `template.html`：遊戲的程式和版面，球員資料的位置留空。CSS 是從棒球版複製過來的，最後一段才是足球專用的樣式。
- `pool.json`：2025-26 英超球季、上場至少 900 分鐘的 339 位球員（門將 24、後衛 128、中場 153、前鋒 34）
- `build.py`：把上面兩個合起來，產生 `epl/index.html`
- `fetch_stats.py`：重新抓數據，更新 `pool.json`

重新產生網頁（在專案根目錄執行）：

    python3 epl/source/build.py

換成新球季的數據（球季結束後再換）：

    python3 epl/source/fetch_stats.py 2026-27
    python3 epl/source/build.py

## 數據來源

Fantasy Premier League（FPL）官方的整季數據，包括 Opta 的 xG、xA、xGC 和防守貢獻。FPL 官網只提供當季資料，所以已經結束的球季改從 GitHub 上的 vaastav/Fantasy-Premier-League 存檔下載，這個存檔每季結束時都會保存一份 FPL 的完整資料。

## 模擬怎麼算

- **總評**：每個位置分開排名，換算方式和棒球版用同一條曲線。數據都是每 90 分鐘的值，並依上場時間往同位置的平均值拉回，上場越少拉得越多。
  - 前鋒、中場：進球和 xG 各占一半，加上助攻和 xA 各占一半，再加防守貢獻。
  - 後衛：進攻貢獻、防守貢獻，以及在場時的 xGC（失球期望值）。
  - 門將：撲救表現（xGC 減實際失球），以及在場時的 xGC。
- **比賽**：每分鐘判定一次雙方會不會起腳射門。
  - 射門機率取決於「我方先發的進攻值」對「對方先發的防守值」，兩者都和 20 支真實球隊的主力陣容比較。
  - 每次射門有自己的 xG，射門的人依 xG/90 抽出。射門後是否進球，取決於 xG、射手的把握度（實際進球 / xG）、體力和對方門將。
  - 主場有優勢。陣型會影響攻守：三後衛失球較多，五後衛失球較少。
- **體力**：比賽中體力會逐漸下降。前兩場有上場的球員，下一場開賽時體力較低。
- **陣容**：每隊 13 人（先發 11 人加 2 名替補），各位置的人數由各隊自己決定。唯一的限制是一定要能排出合法的先發：1 名門將、3–5 名後衛、2–5 名中場、1–3 名前鋒。如果簽下某位球員之後就排不出合法先發，系統不會讓你出價。
- **換人**：只能用那 2 名替補。比賽中的關鍵時刻會詢問你，也可以勾「Auto-manage substitutions」交給系統。
- **戰術**：分五段，Park the bus／Defensive／Balanced／Attacking／All-out attack。越進攻，自己製造的機會越多，但對手的機會也越多，體力也掉得越快。開賽前可以先選，比賽中隨時可以切換，從下一分鐘開始生效，已經播出的內容不會改變。電腦會依比分和時間自己調整戰術。
- **畫面**：球場上會照陣型和戰術畫出兩隊球員。球員外圈的顏色代表體力，被黃牌警告的球員旁邊有黃牌標記。每次射門，球會從射門位置飛向球門，進球時會顯示 GOAL!。下方的 xG 走勢圖會標出每個進球。
- **紅黃牌**：依球員上季每 90 分鐘的黃牌數來抽。
- **測試結果**：20 支真實球隊互踢，每場平均約 2.8 球（實際約 2.7）；主場勝約 43%、和局約 24%。
- **決定性**：比賽由 seed 加上玩家的換人決定重播，結果固定。改模擬時，要注意亂數的消耗順序。
