# 動漫大亂鬥原始檔

網頁是 `anime/index.html`，由這裡的檔案產生。要改遊戲，請改這裡，不要直接改 `anime/index.html`。

- `template.html`：遊戲的程式和版面。前半段的 CSS 是從棒球版複製過來的，後半段才是大亂鬥專用的樣式和紫色配色。
- `roster.json`：40 位角色（10 部作品各 4 人），每人有體力、力量、防禦、速度、必殺技名稱和威力。**數值是依原作自訂的，要調整就改這個檔案。**
- `build.py`：把上面兩個合起來，產生 `anime/index.html`。

改完後重新產生網頁（在專案根目錄執行）：

    python3 anime/source/build.py

## 規則

- 從 40 人中抽 10 位，兩隊各 5 人，預算各 $100。每支籤一定有人拿，沒有流標：輪到你時放棄，對手就以目前價格得標；第一口就放棄的話，對手免費得到他。
- 一隊湊滿 5 人後，剩下的角色自動免費歸另一隊。
- 選完排出場順序（先鋒、次鋒、中堅、副將、大將），進行車輪戰：一對一單挑，贏的人帶著剩下的體力打下一位，每贏一場回復 10% 體力，先全滅的一隊輸。

## 對戰怎麼算

- 兩人輪流出手，速度越快出手越頻繁。普通攻擊可能被閃開（看雙方速度差），10% 機率會心一擊（1.5 倍）。
- 每次出手累積能量，集滿就放必殺技：傷害等於力量乘上必殺技威力，對方的防禦只算六成。速度比對手快 15 以上的人，有 15% 機會閃開必殺技。
- **綜合評價**：開啟網頁時，讓 40 人兩兩單挑各 16 場，依勝率換算成 45–99 分。亂數用固定的種子，所以評價每次都一樣。改了數值，評價會跟著自動變。
- 對戰由種子重播，切換中英文時，同一場比賽會用新語言從頭重播到原來的進度，結果不變。
